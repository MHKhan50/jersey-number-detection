# ⚽ Jersey Number Detection using TensorFlow

A Deep Learning approach for automated player tracking and jersey number identification using TensorFlow and a Custom CNN model.

## 📌 Project Overview
- **Goal:** Automate detection and classification of players based on jersey numbers for sports analytics.
- **Dataset:** Roboflow dataset in TFRecord format.
- **Input Size:** 128x128 RGB images.
- **Model Architecture:** Custom CNN with Conv2D, MaxPool, and GlobalAvgPooling layers.
- **Outputs:** Bounding Box (4 coordinates) & Classification (Binary output).
